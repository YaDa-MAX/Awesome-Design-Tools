# HeiBen — Geschäftsvorlagen (aktuelle CI)

Alle Vorlagen für den Geschäftsalltag, einheitlich in der **aktuellen** Corporate Identity.
Platzhalter stehen in [eckigen Klammern] und werden vor Versand ersetzt.

## CI-Grundlage
- Wortmarke „HeiBen" — H + B in Terracotta (#c2533a), „ei"/„en" in Tinte (#1f1c17)
- Claim „Heimat leben" (Versalien, gesperrt)
- Farben: Papier #f3eee5 · Tinte #1f1c17 · Linie #d8cdb7 · Terracotta #c2533a
- Hausfarben: Reisen #d29939 · Wohnen #4a5c39 · Immobilien #792d29 · Studio #1f1c17 · Kulinarik #6b3951
- Schriften: Fraunces (Überschriften) · Manrope (Fließtext) · JetBrains Mono (Labels/Claim)
- Hinweis: Für die markenechte Darstellung müssen die CI-Schriften auf dem Gerät installiert sein; sonst greift ein Fallback (Word/Excel/PowerPoint ersetzen automatisch).
