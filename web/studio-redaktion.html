Redaktion

Hier legen Sie Beiträge an, bearbeiten und veröffentlichen sie — ganz ohne Programmierkenntnisse. Ihre Arbeit wird automatisch in diesem Browser gespeichert. Über „Sichern & Laden“ sichern Sie alles als Datei oder geben es weiter.

Als Datei sichern

Speichert alle Beiträge in einer Datei namens heiben-magazin-daten.json. Bewahren Sie diese auf oder geben Sie sie an die Person weiter, die Ihre Website betreut. Die Datei enthält nur die Beiträge — keine Leser- oder Nutzungsdaten.

Daten aus Datei laden

Holt eine zuvor gesicherte Datei zurück. Achtung: Die geladenen Beiträge ersetzen den aktuellen Stand in diesem Browser.

Auf Werkseinstellungen zurücksetzen

Stellt die ursprünglichen Beispiel-Beiträge wieder her. Eigene Beiträge in diesem Browser gehen dabei verloren — sichern Sie vorher als Datei, wenn Sie sie behalten möchten.
